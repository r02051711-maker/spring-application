Spring AOP Employee Application

Requirements:
- JDK 17 or later
- Eclipse IDE with Maven support
- Internet connection for the first Maven dependency download

Import into Eclipse:
1. Extract this ZIP file.
2. Open Eclipse.
3. Choose File > Import > Maven > Existing Maven Projects.
4. Browse to the extracted SpringAOPApplication folder.
5. Select the pom.xml project and click Finish.
6. Right-click the project > Maven > Update Project.
7. Open src/main/java/com/example/Main.java.
8. Right-click the editor > Run As > Java Application.

Expected output:
Logging: Adding employee
Employee added: Sathya

Logging: Displaying employee
Employee ID: 101
Employee Name: Sathya

Logging: Calculating salary
Employee Salary: 25000.0
